Sheet A

Control logic and dead-time generation

CH.sch · 1.2 V only

Each arm ends in AND(raw, delayed raw). That makes turn-on wait a full 2 ns while turn-off follows the raw signal immediately, so the two drivers can never be on together.

Sheet B

Forward path — up-shift latch and 3.3 V driver

CH.sch · a_pad → b_pad

Node y is the latch output and also the clamp node. When en = 0, enb_h goes high, MN5 pulls y to ground, z_h goes low, and both gate-drive gates force the output devices off — the pad is high-impedance and nothing is left floating.

Sheet C

Reverse path — down-shift inverter and 1.2 V driver

CH.sch · b_pad → a_pad

The down-shift is a single inverter — no latch, because 3.3 V already reads as a high to 1.2 V logic. It has to be built from HV devices so the 3.3 V gate drive does not punch through the oxide, and that is exactly why it is slow pulling up: the HV PMOS only gets 1.2 V of overdrive.

Sheet D

CTRLLS — the control-signal up-shifter

CTRLLS.sch · ×3 (XL1–XL3)

Three copies of this carry en_up, en and tm into the 3.3 V domain. Each hands back both polarities, so the HV side never needs an inverter to make a complement.

Sheet E

SCHMLV — six-transistor Schmitt trigger

SCHMLV.sch · used at a_pad and after the down-shift

The hysteresis comes entirely from MPF and MNF fighting the input stack. Widening them relative to MN1/MN2 widens the loop — but only where the cell actually sits on the pad, which on the reverse path it does not.

Sheet F

Library cells — inverter, NAND, NOR, NAND3, mux

LV sizes shown; HV cells are identical with hv devices at L = 0.45 µm

Nothing exotic — plain static CMOS. The HV variants (INVHV, NANDHV, NORHV, MUXHV) are the same shapes with sg13_hv_* devices at L = 0.45 µm and wider fingers.

Sheet G

DLY2NS, DFFLV and DIV16

the timing and test-mode cells

Each divider stage feeds its own qb back to d, so it toggles once per input edge, and its q clocks the next stage — four stages give exactly ÷16. In test mode the input is z_l, the recovered data at the end of the ring loop.
